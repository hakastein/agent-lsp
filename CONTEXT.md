# agent-lsp

Слова, которыми о библиотеке говорят решения, комментарии и тесты.

**Корень** (root):
Каталог, который программа передаёт в `Open`, и файлы языка под ним, в том числе через символические ссылки. В Go —
каталог с `go.mod` или `go.work`.
_Avoid_: проект, репозиторий, workspace

**Позиция** (position):
Место вопроса: абсолютный путь, строка и колонка в байтах, обе с 1.

**Symbol**:
Объявление, на которое может указывать использование. В PHP — метод именованного класса, интерфейса, трейта или
enum; имя — полное имя класса и имя метода в нижнем регистре. В Go — функция, метод, тип, поле структуры, метод
интерфейса, переменная и константа верхнего уровня; у метода и поля есть контейнер — тип, в котором они объявлены.

**Объявление** (declaration):
Ответ `Definition`: место имени, диапазон всего объявления без докблока, сигнатура, докблок как он записан в файле и
происхождение.

**Происхождение** (origin):
Где лежит объявление: в корне, в стандартной библиотеке (std), в зависимости вне корня (module) или в
vendor-каталоге корня (vendor).

**Квалифицированное имя** (qualified name):
Имя для `Symbols`: имя с контейнером и пакетом через точку (`pkg.Type.Method`, `Type.Method`, `pkg.Func`); голое
имя сравнивается с последним сегментом. В PHP — `Class::method`.

**Использование** (use):
Место, где имя статически разрешается в Symbol. Совпадение имени без разрешённой цели использованием не является;
такое место — **неразрешённое** (unresolved).
_Avoid_: вхождение, reference

**Связь** (link):
Записанная в индекс пара «место → Symbol». Связи вычисляются при индексации; `References` только читает их.

**Индекс** (index):
То, что `Open` открывает для корня. В PHP — файлы, Symbol и связи одного корня в SQLite на диске; место выбирает
agent-lsp. В Go — сессия форка gopls поверх кэша пользователя.

**Снимок** (snapshot):
Пары «путь → хеш содержимого» файлов корня, из которых построен индекс PHP.

**Кэш пользователя** (user cache):
Одна база SQLite `<os.UserCacheDir()>/agent-lsp/cache.sqlite` для всех корней и языков. Строка без использования 14
дней удаляется.

**Форк gopls** (gopls fork):
Копия внутренних пакетов gopls и `golang.org/x/tools` в `internal/gopls`, которую пакет `golang` вызывает напрямую;
правки перечислены в `internal/gopls/FORK.md`.

**Загрузка пакетов** (load):
Ответ `go list` для корня: пакеты, их файлы и импорты. Хранится в кэше пользователя с **состоянием файлов** — хешем
`go.mod`, `go.sum`, `go.work` и заголовков `.go`-файлов (ограничения сборки, имя пакета, импорты); при том же
состоянии `go list` не запускается.
