# Поставка

Здесь определены упаковка agent-lsp, проверки CI, платформы и выпуск версий.

## Упаковка

agent-lsp поставляется Go-модулем `github.com/hakastein/agent-lsp`. Бинарников и контейнерного образа нет: программа
импортирует пакеты и собирается сама.

Причина: библиотеку вызывают напрямую из процесса программы, без сервера и подпроцессов.

## CI и платформы

- CI — GitHub Actions: gofmt, `go vet` под linux, darwin и windows, тесты на linux; всё с `CGO_ENABLED=0`.
- Платформы — linux, darwin и windows. Код, который зависит от ОС, имеет вариант для каждой из них с той же
  гарантией.

Причина: программы, которые импортируют agent-lsp, собираются без CGO под все три ОС; vet под каждую ловит код,
который на ней не собирается.

## Релиз и версия

Релиз — тег `vX.Y.Z` на `main`, перед которым `CHANGELOG.md` получает раздел `## vX.Y.Z` с изменениями версии.
Версия модуля — тег.

Причина: Go берёт версию модуля из тега, а раздел в `CHANGELOG.md` говорит, что в версии изменилось.
