# Стабы PHP

Каталог `php/stubs` — стабы стандартной библиотеки и расширений PHP из
[JetBrains phpstorm-stubs](https://github.com/JetBrains/phpstorm-stubs): объявления функций, классов и констант с
сигнатурами и докблоками. Код принадлежит JetBrains и авторам phpstorm-stubs и распространяется по лицензии
Apache-2.0 ([LICENSE](LICENSE)). Файл `NOTICE` upstream не ведёт. Файлы скопированы без изменений.

Пакет `php` встраивает каталог в бинарник (`go:embed`) и индексирует `.php`-файлы из него как объявления
стандартной библиотеки (`agentlsp.OriginStd`).

## Что скопировано

Все `.php`-файлы репозитория с их каталогами, кроме:

- `tests/` — тесты стабов;
- `meta/` и файлов `.phpstorm.meta.php` — подсказки PhpStorm, а не объявления;
- `PhpStormStubsMap.php` — карта «имя → файл» для PhpStorm.

Остальные файлы upstream (README, composer.json, настройки CI) не копируются; `LICENSE` копируется.

## Как обновить

1. Скачать архив нового тега: `https://github.com/JetBrains/phpstorm-stubs/archive/refs/tags/<тег>.tar.gz`.
2. Удалить из `php/stubs` всё, кроме этого файла, и скопировать `.php`-файлы по правилам «Что скопировано» вместе
   с `LICENSE`.
3. Записать тег и коммит в таблицу выше, запустить `make go`.

Отдельного номера версии в коде нет: индекс стабов адресован их содержимым, новые стабы индексируются один раз при
первом вызове.
