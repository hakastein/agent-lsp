# agent-lsp

Go-библиотека, которая отвечает на вопросы о коде — объявление, использования, переименование символа — из индекса
корня в SQLite на диске. Программа импортирует её и вызывает напрямую. Задачи — GitHub Issues этого репозитория
(`https://github.com/hakastein/agent-lsp/issues`).

## Правила

- Работа идёт веткой `issue-<N>` от `main`, где `<N>` — номер issue, и пулл-реквестом в `main`; в `main` напрямую не
  пушат.
- Перед кодом — словарь [`CONTEXT.md`](CONTEXT.md) и решения в [`docs/adr/`](docs/adr/). Решение, которое меняет
  записанное, правит ADR в том же коммите.
- API общий для языков: корневой пакет `agentlsp` держит общие типы, пакет языка (`php`, `golang`) — `Open` и
  индекс с теми же методами, что у других языков. Операция, которой язык не умеет, возвращает
  `agentlsp.ErrNotSupported`. Кэш пользователя — одна база SQLite, которую открывает и чистит `internal/cachedb`;
  язык держит в ней свои таблицы.
- `internal/gopls` — форк gopls. Правка в нём записывается в [`internal/gopls/FORK.md`](internal/gopls/FORK.md) в
  том же коммите, иначе upstream не подтянуть; правка, меняющая содержимое кэша, меняет `forkVersion` пакета
  `golang`. Тесты upstream в форк не переносятся, внутренности форка отдельно не тестируются.
- Репозиторий публичный: исходники, выгрузки, пути, имена и числа чужих закрытых проектов сюда не попадают. Ошибка,
  найденная на таком проекте, становится маленькой самописной фикстурой. Код, тесты и документы не называют
  конкретных программ-потребителей и не подстраивают под них поведение.
- Заимствованный код сохраняет уведомление авторов. Сторонние модули подключаются зависимостью в `go.mod`.
- Сборка без CGO: `CGO_ENABLED=0` в `Makefile` и CI. Поэтому `-race` не используется: ему нужен CGO.
- Платформы — linux, darwin, windows. Код, который зависит от ОС, получает вариант для каждой с той же гарантией.
- Go простой и скучный: интерфейс объявляет потребитель, нового понятия под гипотетический случай нет.
- Документы и комментарии описывают текущее состояние.
- Проверка — `make go`: gofmt, `go vet` под linux, darwin и windows, `go test`. CI — `.github/workflows/ci.yml`.
- Релиз — тег `vX.Y.Z` с разделом `## vX.Y.Z` в [`CHANGELOG.md`](CHANGELOG.md).

## Тесты

- Шов — экспортированный API: тест открывает индекс корня через `Open` пакета языка, задаёт вопрос и сверяет места
  в ответе или ошибку. Внутренние таблицы SQLite тесты не читают; исключение — тест `internal/cachedb`, чей
  контракт — чистка таблиц.
- Каталог кэша пользователя у каждого теста свой (`XDG_CACHE_HOME`, `HOME`, `LOCALAPPDATA`): индексы тестов не
  пересекаются и не трогают кэш пользователя.
- Фикстуры — маленькие самописные файлы в `testdata/` пакета языка; место в файле тест находит по уникальной
  подстроке.
- Тест во внешнем пакете `_test`, на testify и таблицах; в теле теста нет логики. Ассерт — на значение.
- Строки диагностики `Open` — не контракт. Тест читает их только там, где другого наблюдаемого нет: было ли
  переиспользование индекса и какой файл пропущен.
